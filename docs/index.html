The Challenge

More reporting doesn't always mean better visibility.

Enterprise portfolios generate large volumes of weekly status updates. But leaders need more than a collection of green, amber, and red indicators. They need to understand what changed, which dependencies are at risk, and where intervention or decisions may be required.

This prototype explores how deterministic portfolio analysis and generative AI can work together to bridge that gap.

Approach

How the prototype works

The design separates factual calculations from AI-generated narrative, so the model is not responsible for determining the underlying portfolio changes.

01

Ingest

Read and validate structured weekly Excel portfolio data.

02

Compare

Calculate changes in status, milestones, risks, and dependencies.

03

Synthesize

Use the OpenAI API to produce an executive-oriented narrative.

04

Evaluate

Check selected claims against structured portfolio evidence.

Design principle: Python calculates the changes. Generative AI explains their significance. Targeted automated checks help identify selected unsupported claims, while human review remains necessary.
Transparency

A tested prototype, not a production deployment.

The project includes an end-to-end processing pipeline and 13 automated tests covering ingestion, portfolio comparison, and selected executive-brief evaluation scenarios.

All demonstration data is synthetic. The application is not deployed within an enterprise, does not provide a live dashboard, and does not comprehensively verify every AI-generated statement.
